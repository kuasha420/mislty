首页 -> 网络连接

1. 页面左侧的流量显示框用于显示数据流量及连接时长。

“连接”按钮用于手动连接3G网络。当3G网络处于连接状态时，该按钮将显示为“断开”按钮，用于手动断开3G网络。当菜单“3G->连接模式”设置为“自动拨号”时，手动断开3G网络后，uFi设备会再自动连接3G网络。

“刷新”按钮用于刷新数据流量和连接时长数据的显示。

2. 页面右侧的“接入用户列表”用于显示WIFI连接用户数量及其终端设备的MAC地址。

首页 -> 恢复出厂设置

“恢复出厂设置”按钮用于将uFi设备的参数恢复为出厂设置，并重新启动uFi设备。

首页 -> DHCP设置

“IP地址”用于设置uFi设备的IP地址，此“IP地址”也是管理网页的登录地址。“IP地址”出厂设置为“192.168.100.1”。

“子网掩码”出厂设置为“255.255.255.0”。

“IP地址范围”用于设置为终端设备动态分配的IP地址范围段，出厂设置为“192.168.100.100-192.168.100.200”。

注意：“DHCP设置”修改后，请点击“应用”按钮，并需要重新启动uFi设备，修改后的设置才会生效。

首页 -> 修改密码

用于修改管理网页登录密码。管理网页登录帐号和密码的出厂设置都为“admin”。

3G -> 连接模式

用于设置3G网络的连接方式。对于“手动拨号”方式，3G网络的连接和断开在“首页->网络连接”菜单里操作。

3G -> 网络选择

用于优选网络制式。出厂设置是“自动”匹配。

3G -> APN设置

用于设置对应运营商所提供的3G网络的接入参数，包括拨号号码、用户名、密码、APN。请用户向对应的运营商询问接入参数。

Wi-Fi -> 基本设置

用于设置Wi-Fi网络模式、网络名称（SSID）、网络广播、信道和最大接入数。

用户可自行定义Wi-Fi网络的名称（SSID），方便自己记忆和识别。

如果“网络广播”设置为“禁用”，则终端设备在搜索Wi-Fi网络时，此网络名称不会显示在终端设备搜索到的Wi-Fi网络列表里，需要用户自己手工添加网络。

注意：“Wi-Fi基本设置”修改后，请点击“应用”按钮，并需要重新启动uFi设备，修改后的设置才会生效。

Wi-Fi -> 安全设置

用于设置Wi-Fi网络连接密码。

注意：“Wi-Fi安全设置”修改后，请点击“应用”按钮，并需要重新启动uFi设备，修改后的设置才会生效。

Wi-Fi -> 休眠设置

用于启用或者禁用Wi-Fi模块的休眠模式。

如果启用了Wi-Fi休眠，则需要设置“休眠时长”，即在设定的“休眠时长”后，如果一直没有终端设备连接Wi-Fi网络，则Wi-Fi模块进入休眠状态。

Wi-Fi -> 接入用户

用于显示WIFI连接用户数量及其终端设备的MAC地址。

状态 -> 数据统计

用于显示当前上下行数据传输速率、数据传输量和连接时长。

状态 -> 基本状态

用于显示当前3G连接的网络运营商、网络类型、以及uFi设备的软硬件版本、IMEI等信息。

状态 -> 网络状态

用于显示WAN/WLAN/LAN的相关连接状态和IP地址等信息。
