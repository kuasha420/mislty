首頁 -> 網絡連接

1. 頁面左側的流量顯示框用于顯示數據流量及連接時長。

“連接”按鈕用于手動連接3G網絡。當3G網絡處于連接狀態時，該按鈕將顯示爲“斷開”按鈕，用于手動斷開3G網絡。當菜單“3G->連接模式”設置爲“自動撥號”時，手動斷開3G網絡後，uFi設備會再自動連接3G網絡。

“刷新”按鈕用于刷新數據流量和連接時長數據的顯示。

2. 頁面右側的“接入用戶列表”用于顯示WIFI連接用戶數量及其終端設備的MAC地址。

首頁 -> 恢複出廠設置

“恢複出廠設置”按鈕用于將uFi設備的參數恢複爲出廠設置，並重新啓動uFi設備。

首頁 -> DHCP設置

“IP地址”用于設置uFi設備的IP地址，此“IP地址”也是管理網頁的登錄地址。“IP地址”出廠設置爲“192.168.100.1”。

“子網掩碼”出廠設置爲“255.255.255.0”。

“IP地址範圍”用于設置爲終端設備動態分配的IP地址範圍段，出廠設置爲“192.168.100.100-192.168.100.200”。

注意：“DHCP設置”修改後，請點擊“應用”按鈕，並需要重新啓動uFi設備，修改後的設置才會生效。

首頁 -> 修改密码

用于修改管理網頁登錄密碼。管理網頁登錄帳號和密碼的出廠設置都爲“admin”。

3G -> 連接模式

用于設置3G網絡的連接方式。對于“手動撥號”方式，3G網絡的連接和斷開在“首頁->網絡連接”菜單裏操作。

3G -> 網絡選擇

用于優選網絡制式。出廠設置是“自動”匹配。

3G -> APN設置

用于設置對應運營商所提供的3G網絡的接入參數，包括撥號號碼、用戶名、密碼、APN。請用戶向對應的運營商詢問接入參數。

Wi-Fi -> 基本設置

用于設置Wi-Fi網絡模式、網絡名稱（SSID）、網絡廣播、信道和最大接入數。

用戶可自行定義Wi-Fi網絡的名稱（SSID），方便自己記憶和識別。

如果“網絡廣播”設置爲“禁用”，則終端設備在搜索Wi-Fi網絡時，此網絡名稱不會顯示在終端設備搜索到的Wi-Fi網絡列表裏，需要用戶自己手工添加網絡。

注意：“Wi-Fi基本設置”修改後，請點擊“應用”按鈕，並需要重新啓動uFi設備，修改後的設置才會生效。

Wi-Fi -> 安全設置

用于設置Wi-Fi網絡連接密碼。

注意：“Wi-Fi安全設置”修改後，請點擊“應用”按鈕，並需要重新啓動uFi設備，修改後的設置才會生效。

Wi-Fi -> 休眠設置

用于啓用或者禁用Wi-Fi模塊的休眠模式。

如果啓用了Wi-Fi休眠，則需要設置“休眠時長”，即在設定的“休眠時長”後，如果壹直沒有終端設備連接Wi-Fi網絡，則Wi-Fi模塊進入休眠狀態。

Wi-Fi -> 接入用戶

用于顯示WIFI連接用戶數量及其終端設備的MAC地址。

狀態 -> 數據統計

用于顯示當前上下行數據傳輸速率、數據傳輸量和連接時長。

狀態 -> 基本狀態

用于顯示當前3G連接的網絡運營商、網絡類型、以及uFi設備的軟硬件版本、IMEI等信息。

狀態 -> 網絡狀態

用于顯示WAN/WLAN/LAN的相關連接狀態和IP地址等信息。
